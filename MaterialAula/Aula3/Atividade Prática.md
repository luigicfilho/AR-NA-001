# Atividade Prática 3

Objetivo: Desenhando a Arquitetura de um Sistema de E-commerce

## Cenário

Você faz parte de uma equipe de desenvolvimento de software e foi encarregado de projetar a arquitetura de um novo sistema de e-commerce. Este sistema deve permitir que os usuários naveguem por produtos, adicionem itens ao carrinho, realizem pagamentos e acompanhem seus pedidos. Os administradores precisam gerenciar produtos, usuários e pedidos.

## Objetivos

Esta atividade tem como objetivo demonstrar a aplicação dos conceitos de Arquitetura Limpa (Clean Architecture) e diferentes estilos arquiteturais (Monolito, SOA, Microsserviços) em um cenário prático de desenvolvimento de software.

## Tarefas

1.  **Análise Inicial e Arquitetura Limpa:**
    *   Identifique os casos de uso principais do sistema de e-commerce (por exemplo, `Realizar Pedido`, `Gerenciar Produto`, `Navegar Produtos`).
    *   Para um desses casos de uso (escolha um), descreva como a Arquitetura Limpa seria aplicada, detalhando as camadas (Entidades, Casos de Uso, Adaptadores de Interface, Frameworks e Drivers) e as dependências entre elas.

2.  **Proposta de Arquitetura - Monolito:**
    *   Descreva como o sistema de e-commerce seria arquitetado como um **Monolito**. Quais seriam os principais módulos ou componentes? Quais as vantagens e desvantagens dessa abordagem para este sistema?

3.  **Proposta de Arquitetura - SOA (Arquitetura Orientada a Serviços):**
    *   Descreva como o sistema de e-commerce seria arquitetado utilizando **SOA**. Identifique pelo menos três serviços distintos que poderiam compor essa arquitetura e como eles se comunicariam. Quais as vantagens e desvantagens dessa abordagem para este sistema?

4.  **Proposta de Arquitetura - Microsserviços:**
    *   Descreva como o sistema de e-commerce seria arquitetado utilizando **Microsserviços**. Identifique pelo menos cinco microsserviços que poderiam compor essa arquitetura e como eles se comunicariam. Quais as vantagens e desvantagens dessa abordagem para este sistema?
