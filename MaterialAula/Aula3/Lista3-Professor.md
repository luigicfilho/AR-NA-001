# Lista Exercícios 3

1. Qual camada na Clean Architecture contém regras de negócio?
A) Interface  
B) Framework  
C) Entidade  
D) Controller  

**Resposta correta:** C  

2. O que caracteriza alta coesão?   
A) Módulo com múltiplas funções distintas  
B) Módulo focado em uma única responsabilidade  
C) Várias dependências externas  
D) Código espalhado em várias camadas  

**Resposta correta:** B  

3. Qual arquitetura usa ESB para integração?  
A) Monolito  
B) Microsserviços  
C) SOA  
D) Serverless  

**Resposta correta:** C  

4. Qual é uma vantagem do monolito? 
A) Escala por partes  
B) Deploy complexo  
C) Simplicidade inicial  
D) Autonomia de equipes  

**Resposta correta:** C  

5. Em microsserviços, cada serviço geralmente tem seu próprio: 
A) Time de marketing  
B) Banco de dados  
C) Documento de requisitos  
D) Manual de usuário  

**Resposta correta:** B  

6. Qual é um desafio dos microsserviços?  
A) Baixo custo operacional  
B) Simplicidade no monitoramento  
C) Alta complexidade de rede  
D) Único pipeline de CI/CD  

**Resposta correta:** C  

7. Onde ficam os frameworks na Clean Architecture?  
A) Centro  
B) Camada intermediária  
C) Camada externa  
D) Entre entidades e casos de uso  

**Resposta correta:** C  

8. Qual modelo tem maior granularidade?
A) Monolito  
B) SOA  
C) Microsserviços  
D) Cliente-Servidor  

**Resposta correta:** C  

9. O que é baixo acoplamento? 
A) Módulos fortemente interligados  
B) Módulos que não dependem uns dos outros  
C) Um módulo controla todos os outros  
D) Todos os módulos compartilham banco  

**Resposta correta:** B  

10. Qual arquitetura é mais indicada para MVP? 
A) Microsserviços  
B) SOA  
C) Monolito  
D) Mesh de serviços  

**Resposta correta:** C
