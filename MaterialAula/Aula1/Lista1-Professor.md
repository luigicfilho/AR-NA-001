# Lista de exercícios 1

1. Qual é o principal objetivo da arquitetura de software?
a) Melhorar apenas a estética do código
b) Organizar a estrutura do sistema e orientar decisões técnicas
c) Reduzir o número de desenvolvedores necessários
d) Criar interfaces mais bonitas

Resposta correta: b
Explicação: A arquitetura de software define a estrutura do sistema, seus módulos e interações, orientando decisões técnicas e estratégicas.

2. Qual estilo arquitetural é caracterizado por um único bloco de código e deploy único?
a) Microsserviços
b) Monolítico
c) Orientado a eventos
d) Hexagonal

Resposta correta: b
Explicação: A arquitetura monolítica reúne todo o sistema em um único bloco, facilitando o início, mas dificultando a escalabilidade.

3. O que caracteriza uma arquitetura baseada em microsserviços?
a) Todos os módulos no mesmo processo
b) Serviços independentes e escaláveis separadamente
c) Falta de comunicação entre componentes
d) Exclusivamente uso de banco de dados distribuído

Resposta correta: b
Explicação: Microsserviços são serviços independentes que podem ser desenvolvidos, implantados e escalados individualmente.

4. Qual padrão separa operações de leitura e escrita para melhorar desempenho?
a) MVC
b) CQRS
c) Event Sourcing
d) Arquitetura em Camadas

Resposta correta: b
Explicação: CQRS (Command Query Responsibility Segregation) separa comandos (escrita) de consultas (leitura).

5. Qual é o impacto direto de uma arquitetura mal planejada?
a) Custos de manutenção menores
b) Evolução mais fácil do sistema
c) Retrabalho e dificuldade de escalabilidade
d) Maior segurança e performance

Resposta correta: c
Explicação: Arquitetura mal planejada leva a sistemas frágeis, difíceis de manter e escalar.

6. Em sistemas orientados a eventos, os componentes…
a) São fortemente acoplados
b) Reagem a notificações disparadas no sistema
c) Não precisam de mensageria
d) São sempre síncronos

Resposta correta: b
Explicação: Sistemas orientados a eventos disparam notificações e outros componentes reagem de forma assíncrona.

7. Qual papel conecta requisitos de negócio e decisões técnicas?
a) Tester
b) Arquiteto
c) Gerente de Produto/Projeto
d) DevOps

Resposta correta: c
Explicação: O gerente conecta necessidades de negócio com as decisões técnicas para alinhar escopo e arquitetura.

8. Qual técnica reduz o tempo de resposta ao evitar consultas repetidas?
a) Fila de mensagens
b) Caching
c) Banco distribuído
d) Arquitetura em camadas

Resposta correta: b
Explicação: O cache armazena dados temporariamente, reduzindo consultas ao banco e acelerando respostas.

9. Qual tendência traz processamento para mais perto do usuário, reduzindo latência?
a) Edge Computing
b) Serverless
c) IA em arquiteturas
d) Microsserviços

Resposta correta: a
Explicação: O Edge Computing processa dados próximo ao usuário, reduzindo a necessidade de envio para servidores centrais.

10. Qual ferramenta ou modelo é simples e foca em contexto, contêineres, componentes e código?
a) UML
b) BPMN
c) C4
d) REST

Resposta correta: c
Explicação: O modelo C4 usa quatro níveis de abstração para documentar a arquitetura de forma simples e clara.
