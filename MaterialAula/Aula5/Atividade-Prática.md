# Atividade prática

## Simulação de Processamento Batch com Dados de Vendas

Objetivo: Compreender como o processamento em lote funciona com dados acumulados e agendados.

Materiais: Planilha CSV com dados de vendas diárias: `Coffe_sales.csv`

## Passos a seguir:

1. Os alunos devem usar o dataset simulado de vendas diárias (`Coffe_sales.csv`).

2. Agrupar os dados por produto e calcular o total de vendas.

3. Programar um script para processar os dados diariamente (simulado com um agendador simples).

4. Discutir como a latência afeta a tomada de decisões quando os dados são processados apenas uma vez ao dia.
