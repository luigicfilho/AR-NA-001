# Lista de Exercicios 5

**1. Qual modelo de processamento é ideal para gerar relatórios financeiros mensais?**  
A) Stream  
B) Micro-batch  
C) Batch  
D) Real-time Lambda  
✅ **Resposta: C) Batch**

**2. Qual modelo oferece a menor latência?**  
A) Batch  
B) Micro-batch  
C) Stream  
D) ETL tradicional  
✅ **Resposta: C) Stream**

**3. O Apache Flink é mais adequado para qual modelo?**  
A) Batch puro  
B) Micro-batch apenas  
C) Stream real com estado  
D) Backup incremental  
✅ **Resposta: C) Stream real com estado**

**4. Em qual cenário NÃO se recomenda stream processing?**  
A) Detecção de fraude em cartões  
B) Monitoramento de batimentos cardíacos  
C) Geração de folha de pagamento  
D) Trading algorítmico  
✅ **Resposta: C) Geração de folha de pagamento**

**5. O que caracteriza o micro-batch?**  
A) Processamento registro a registro sem janelas  
B) Processamento em lotes de segundos ou minutos  
C) Processamento apenas uma vez por dia  
D) Uso exclusivo de SQL tradicional  
✅ **Resposta: B) Processamento em lotes de segundos ou minutos**

**6. Qual ferramenta pode ser usada tanto para batch quanto para micro-batch?**  
A) Apache Kafka (sozinho)  
B) Apache Spark  
C) MySQL sem triggers  
D) FTP Server  
✅ **Resposta: B) Apache Spark**

**7. Qual é o principal trade-off do stream processing?**  
A) Baixa latência vs. baixo custo  
B) Alta confiabilidade vs. simplicidade  
C) Baixa latência vs. alta complexidade/custo  
D) Alta latência vs. baixa manutenção  
✅ **Resposta: C) Baixa latência vs. alta complexidade/custo**

**8. O que é checkpointing em stream processing?**  
A) Backup diário do sistema  
B) Mecanismo para salvar estado e recuperar após falha  
C) Exportação de dados para CSV  
D) Limpeza de cache a cada 5 minutos  
✅ **Resposta: B) Mecanismo para salvar estado e recuperar após falha**

**9. Qual modelo é mais fácil de debugar?**  
A) Stream  
B) Micro-batch  
C) Batch  
D) Todos são igualmente fáceis  
✅ **Resposta: C) Batch**

**10. Em sistemas de IoT críticos (como UTI), qual modelo é essencial?**  
A) Batch  
B) Micro-batch  
C) Stream  
D) Planilha Excel  
✅ **Resposta: C) Stream**
